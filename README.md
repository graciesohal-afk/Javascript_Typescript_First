# JavaScript and TypeScript

A collection of beginner-friendly JavaScript practice files and setup checks.

## Getting started

Install [Node.js](https://nodejs.org/), then run a file from the project directory:

```powershell
node .\chapter_01_basics\01_Basics.js
```

## Project files

- `chapter_01_basics/01_Basics.js` - introductory console output and variables.
- `02_JS.js` - basic variables, loops, and functions.
- `03_JS_Verify_Setup.js` - Node.js platform and architecture checks.

# Visual Studio Code Shortcuts for Windows

Shortcuts below use the default Windows keybindings. `Ctrl` means Control, `Shift` means Shift, and `Alt` means Alt.

## Editing

| Action | Shortcut |
| --- | --- |
| Copy line (or selection) down | `Shift+Alt+Down` |
| Move line up or down | `Alt+Up` / `Alt+Down` |
| Delete line | `Ctrl+Shift+K` |
| Insert line below | `Ctrl+Enter` |
| Insert line above | `Ctrl+Shift+Enter` |
| Toggle line comment | `Ctrl+/` |
| Format document | `Shift+Alt+F` |
| Find in the current file | `Ctrl+F` |
| Replace in the current file | `Ctrl+H` |
| Undo / redo | `Ctrl+Z` / `Ctrl+Y` |

## Files and navigation

| Action | Shortcut |
| --- | --- |
| Quick Open a file | `Ctrl+P` |
| Show all commands | `Ctrl+Shift+P` |
| Open or close the integrated terminal | `Ctrl+`` |
| Switch between open editors | `Ctrl+Tab` |
| Go to a line | `Ctrl+G` |
| Go to definition | `F12` |
| Rename symbol | `F2` |
| Save | `Ctrl+S` |
| Close the current editor | `Ctrl+W` |

## Selecting and multiple cursors

| Action | Shortcut |
| --- | --- |
| Add cursor above or below | `Ctrl+Alt+Up` / `Ctrl+Alt+Down` |
| Add the next occurrence to the selection | `Ctrl+D` |
| Select all occurrences | `Ctrl+Shift+L` |
| Select the current line | `Ctrl+L` |

Shortcut assignments can vary if you have changed keybindings or installed extensions. Open **File > Preferences > Keyboard Shortcuts** or press `Ctrl+K`, then `Ctrl+S` to search or customize them.
